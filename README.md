# A full-stack browser messaging app brought from the future to keep you, your family, friends, and fellow programmers connected.

Please note this repo was forked because it was created on our project lead's account. You can view the original here: https://github.com/hotoke-2025/whats-up 

Build using React with a database and Auth0 integrated sign-in/out
Our stretch goal was to have the ability to join a group chat with 3 or more people, but as we only had a week to work on it, we ended up running out of time. However, our main goal as a team was focused on learning and teamwork, rather than the end product.

link to deployed site: https://whats-up-zh1w.onrender.com/
